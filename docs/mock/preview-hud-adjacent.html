타일을 붙여 배치했을 때의 A안

프리뷰를 위아래·양옆 간격 없이 붙인 상태입니다. 왼쪽이 지금의 A안, 오른쪽이 붙여 놓아도 경계가 보이게 보강한 A+입니다. 두 배치 모두 같은 상태를 같은 자리에 두었습니다. (평상시·활성 / 디스럽터 / 스크램블 / HIC / 피격 급증 / 스크램블+급증)

현재 A

활성은 초록 테두리, 급증은 빨간 테두리+색조

A+ (인접 배치 보강)

타일 안쪽 검은 경계선, 이름 라벨 뒤판, 더 큰 리본(검은 윤곽), 활성=흰 이중 테두리, 급증 테두리 안쪽에 검은 선
붙여 놓으면 생기는 문제와 A+의 대응
  • 경계가 사라짐: 게임 화면이 어두워서 타일끼리 하나로 이어져 보입니다. → 타일 안쪽에 검은 1px 경계선을 둡니다.
  • 리본과 이웃의 이름 라벨이 붙어 보임: 리본은 오른쪽 위, 라벨은 왼쪽 위라 붙으면 서로 이어집니다. → 라벨에 어두운 뒤판을 씌우고 리본에는 검은 윤곽을 줍니다.
  • 빨간 테두리가 이웃으로 번져 보임: 붙어 있는 두 타일이 모두 급증이면 하나의 큰 붉은 덩어리처럼 보입니다. → 테두리 안쪽에 검은 선을 하나 더 둬서 타일 단위로 끊어 보이게 합니다.
  • 급증 색조가 리본 색을 바꿈: 붉은 색조가 리본을 덮으면 스크램블 파랑이 보라로 보입니다. → 리본은 항상 색조 위에 그려 원래 색을 유지합니다.
  • 초록 활성 테두리와 디스럽터 초록의 혼동: 활성은 흰색 이중 테두리로 바꿔 색이 겹치지 않게 합니다.
